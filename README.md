# Budget Tracker CLI

Интерактивный CLI-контроллер для управления бюджетными счетами и транзакциями с использованием библиотеки inquirer

## Возможности

- просмотр списка всех счетов;
- создание нового счёта;
- просмотр баланса и транзакций выбранного счёта;
- добавление доходов и расходов;
- удаление транзакций;
- удаление счёта вместе со связанными транзакциями;
- экспорт транзакций в CSV-файл;

## Установка проекта

Клонируйте репозиторий:

```
git clone https://github.com/mad-hat-ter/budget-tracker-cli.git
```

Перейдите в папку проекта:

```
cd budget-tracker-cli
```

Установите зависимости:

```
npm install
```

## Запуск проекта

Для запуска приложения выполните:

```
npm start
```

После запуска откроется интерактивное меню приложения

## Сборка проекта

Для компиляции проекта выполните:

```
npm run build
```

После сборки приложение можно запустить командой:

```
node dist/index.js
```

## Основная навигация

После запуска доступны следующие действия:

1. Выбрать существующий счёт
2. Создать новый счёт
3. Выйти из приложения

В меню выбранного счёта можно:

- добавить транзакцию;
- удалить транзакцию;
- экспортировать транзакции в CSV;
- удалить счёт;
- вернуться к списку счетов

## Добавление транзакции

При создании транзакции необходимо указать:

- сумму;
- тип: доход или расход;
- дату в формате `YYYY-MM-DD`;
- описание

Сумма должна быть положительным числом
Если дата не указана, используется текущая дата

## Экспорт в CSV

Для экспорта выберите пункт:

Экспортировать транзакции в CSV

Затем укажите имя файла без расширения

Файл сохраняется в текущей рабочей папке проекта

## Архитектура проекта

### `Transaction`

Класс описывает отдельную транзакцию:

- доход;
- расход;
- сумму;
- дату;
- описание;
- уникальный идентификатор

### `Account`

Класс представляет отдельный счёт. Он хранит транзакции и рассчитывает:

- общую сумму доходов;
- общую сумму расходов;
- текущий баланс

### `AccountManager`

Класс управляет всеми счетами приложения:

- добавляет счета;
- удаляет счета;
- ищет счёт по ID;
- рассчитывает общий баланс

### `ApplicationController`

Основной контроллер приложения. Отвечает за:

- главное меню;
- создание счетов;
- просмотр счетов;
- добавление и удаление транзакций;
- удаление счетов;
- экспорт данных
